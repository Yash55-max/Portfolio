Architecture & Implementation

Engineered modular Terraform configurations provisioning Amazon EKS (Kubernetes v1.35), custom multi-AZ VPC networking, and least-privilege IAM Roles for Service Accounts (IRSA). Deployed containerized Ollama and FastAPI inference gateways decoupled via Kubernetes ClusterIP service discovery.
