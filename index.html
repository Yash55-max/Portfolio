  • Modular Terraform provisions VPC 10.0.0.0/16 across ap-south-1a & ap-south-1b, t3.small managed nodes, and OIDC least-privilege IRSA (ebs-csi-irsa) for dynamic EBS gp3 storage.

11.2026 · v1.2.0 Linux Thermal & Power Control Center

Native Linux desktop application & headless CLI (asus-thermals-control v1.2.0) for monitoring hardware telemetry and actively governing temperatures, cooling policies, fan curves, and ACPI battery charge limits.

  • Closed-loop graduated thermal limiter tested reducing sustained CPU peak temperature from 84.5°C to 68°C–71°C (~15°C–16°C cooler) while sustaining 92% compute throughput.
  • Enforces strict PWM fan safety rails (50 PWM / ~20% stall floor, 80.0°C emergency automatic reset, plus SIGINT/SIGTERM/SIGHUP/atexit hardware state cleanup).
  • Verified on ASUS Vivobook Go E1504FA (Ryzen 5 7520U k10temp, Radeon 610M amdgpu, NVMe, asus-nb-wmi) with Intel/NVIDIA hwmon support, battery caps (60%/80%/100%), .deb/PKGBUILD/RPM packaging, and --json CLI for Waybar/Polybar.

Limitation: Custom PWM fan speed and battery charge threshold writes depend on kernel hwmon / WMI driver exposure on the host laptop.
